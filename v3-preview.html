03 — ENGINEERING DISCIPLINE

NO MAGIC.
JUST EVIDENCE.

A habit of tracing failures, minimizing changes, and being precise about test evidence.

01 / FIND IT

Reproduce the bug.

Get the original failure on a clean baseline. Observe the behavior, isolate the root cause, and create a meaningful failing regression.

RED → reproduce
02 / FIX IT

Change the right line.

Make the smallest safe change, with clear reasoning about compatibility and lifecycle edge cases. Keep it maintainable.

GREEN → verify
03 / PROVE IT

Survive review.

Run real tests, check CI, discuss feedback and distinguish successful checks from actual upstream acceptance.

REVIEW → merge

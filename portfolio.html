02 / DART-CODE

Faster test suites without real tool launches

MERGED — NOV 07 2026

01 / The problem

Command tests spawned real Dart and Flutter tools, adding tool and network overhead for behavior that could be tested deterministically.

02 / The fix

Introduced process stubs and explicit output assertions, avoiding unnecessary real command launches while keeping relevant behavior covered.

03 / The evidence

One focused Flutter test group went from ~24s to ~3s locally. DanTup approved the revised PR and it merged Nov 7.

Making async callbacks safe after disposal

MERGED — NOV 05 2026

01 / The problem

Asynchronous events and service callbacks could continue after VS Code extension disposal and cause unhandled rejections.

02 / The fix

Added shutdown and lifecycle guards, plus regression coverage for disposal races and pending asynchronous work.
